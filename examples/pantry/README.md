# Example — Pantry (phases 0–4)

A worked example of the workflow applied to the *pantry manager* idea. It shows what "done" looks like for each early deliverable. Content is illustrative — when the real project starts, run `/project-bootstrap` in its own repo.

| Phase | Deliverable | File |
|---|---|---|
| 0 · Idea intake | Idea card + score | [`notion/idea.md`](notion/idea.md) |
| 1 · Discovery | Project brief | [`docs/project-brief.md`](docs/project-brief.md) |
| 2 · Design | Design index (flows, screen inventory, style guide) | [`docs/design.md`](docs/design.md) |
| 3 · Architecture | Architecture doc + ADRs | [`docs/architecture.md`](docs/architecture.md), [`docs/adr/`](docs/adr/) |
| 4 · Planning | Milestones, feature spec, task breakdown | [`notion/milestones.md`](notion/milestones.md), [`docs/specs/expiry-alerts.md`](docs/specs/expiry-alerts.md), [`notion/tasks-expiry-alerts.md`](notion/tasks-expiry-alerts.md), [`notion/tasks-expiry-alerts.csv`](notion/tasks-expiry-alerts.csv) |

Project prefix: **PAN**. Stack: Flutter + drift (SQLite), offline-first, single user.
