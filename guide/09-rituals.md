# 09 · Rituals

Two rituals only. Use a recurring calendar block so they actually happen.

## Weekly review — 30 min (e.g. Sunday evening)

Create a page from the [weekly review template](../templates/notion/weekly-review.md) and go through:

1. **Look back (5 min)** — Throughput chart: what got Done this week? Celebrate it, briefly.
2. **Board health (10 min)**
   - *Aging WIP* view: anything In Progress > 5 days? Split it, spike it, or unblock it.
   - WIP limits respected? (In Progress ≤ 2, Review/Test ≤ 2)
   - Blocked tasks: what's the next action to unblock?
3. **Replenish Ready (10 min)** — Refine Backlog tasks until Ready has 5–10 tasks meeting DoR, ordered by priority.
4. **Milestone health (3 min)** — Progress % vs. time elapsed on the timeline. Set *Health*: On track / At risk / Blocked. If At risk: cut scope or move the date — decide now.
5. **Plan the week (2 min)** — Pick the 1–3 tasks you intend to finish. Note available hours.

## Milestone review — 45 min (at the end of each milestone)

1. **Release** steps from [chapter 07](07-release.md).
2. **Retro** with the [milestone retro template](../templates/notion/milestone-retro.md):
   - Planned vs delivered (task count, dates).
   - Median cycle time and throughput for the milestone.
   - Went well / didn't go well / surprised me.
   - 1–3 actions (each becomes a task or a change in the Grimorio repo).
3. **Plan** the next milestone ([chapter 05](05-planning.md)).

## Daily (optional, 2 min)

At the start of a work session: open the board, re-read the task you're on, write the *one thing* you'll finish this session.
At the end: leave a one-line note in the task (*"Next: wire the delete button"*) so you can resume instantly.
